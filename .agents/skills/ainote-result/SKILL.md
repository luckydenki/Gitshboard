## 수행할 내용

`/AI-productivity/mainagent`와 `/AI-productivity/subagent` 안에 있는 지시자가 확인하라는 토큰 분석 md 파일을 열어본 후 두개를 비교 분석하여 규격에 맞게 분석 결과를 문서로 만든다.

문서제목은 AI-productivity 아래 `Result-[파일이름].md`로 지어서 작성한다.
