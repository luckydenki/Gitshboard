# API 코드 이해도 비교

실험 실행을 요청받았을 때 평가 세션을 생성한다.

## 준비

1. 같은 API의 변경 전후 스냅샷을 고정한다. 엔드포인트, 인증과 버전, 페이지 기본값, 반환 필드 및 오류 처리가 동등한지 확인한다. 동작 차이가 있으면 비교 전에 맞추거나 결과에 명시한다.
2. 평가 입력은 버전별 해당 API 코드 한 파일로 제한한다. 양쪽에서 같은 역할을 하는 범위를 정해 물리적 줄 수를 집계하고 빈 줄과 주석의 포함 여부를 기록한다. 공통 설정이나 헬퍼로 이동한 줄은 별도 집계한다.
3. 실행 전에 정답표를 만든다. 복합 문항은 1점에 필요한 요소를 명시한다. 코드에 import만 보이면 설정의 출처와 파일에서 확인할 수 없는 값을 구분한 답을 인정한다.

## 실행

- 사용 가능한 경량 구버전 모델 하나를 고르고 정확한 모델 ID와 추론 설정을 기록한다. 지정한 모델이나 격리 환경을 사용할 수 없으면 제약을 밝힌다.
- 매 실행에 이전 대화가 없는 독립 세션을 사용한다. 해당 API 코드를 프롬프트에 직접 넣고, 웹 검색, 이전 세션 조회, 다른 파일 및 셸 접근을 차단한다. 비교 버전, 정답표, 다른 세션의 답변은 평가 모델에 제공하지 않는다.
- 두 버전에서 동일한 프롬프트와 답변 길이 제한을 사용한다. 반복 횟수를 사전에 정하고 양쪽 횟수와 동시 실행 수준을 맞춘 뒤 순서를 섞는다. 예비 실험에서 양쪽이 거의 모두 맞히거나 틀리면 본 실험 전에 모델이나 문항을 조정하고 예비 결과를 분리한다.
- 프롬프트 제출부터 최종 답변 완료까지 측정한다. 시간 초과, 인프라 오류 및 격리를 확인할 수 없는 실행을 별도로 기록한다.

## 평가 프롬프트

> 아래에 제공된 API 코드만 읽어라. 인터넷, 다른 세션 정보, 다른 파일을 조회하지 마라. 다음 문항을 순서대로 문항당 최대 두 문장으로 답하라. 코드에서 확인할 수 없는 정보는 확인할 수 없다고 써라.

## 집계

- 문항별로 0점 또는 1점을 주고 4문항 중 3개 이상 맞히면 통과로 기록한다. 버전, 문항별 점수, 통과 여부, 경과 시간과 제외 사유를 실행별로 남긴다.
- 코드 감소율 = (변경 전 줄 수 − 변경 후 줄 수) ÷ 변경 전 줄 수 × 100. 집계 범위와 별도로 센 공유 코드를 함께 보고한다.
- 문항 정확도 = 정답 수 ÷ 채점한 전체 문항 수 × 100. 통과율 = 통과 실행 수 ÷ 채점 실행 수 × 100. 표본 수, 문항별 정확도와 버전 간 정확도 차이(%p)를 함께 보고한다.
- 완료한 전체 실행과 통과한 실행의 시간 중앙값을 각각 비교한다. 시간 감소율 = (변경 전 중앙값 − 변경 후 중앙값) ÷ 변경 전 중앙값 × 100. 제외한 실행의 수와 사유를 명시하고 누락 시간은 추정하지 않는다.
- 결과는 고정 모델이 한 파일을 읽었을 때의 이해도로 해석한다. 답변 완료 시간에는 모델 실행 지연이 포함된다. 공통 설정까지 탐색하는 이해도는 양쪽에 같은 기준으로 필요한 파일을 제공하는 별도 실험으로 측정한다.
