자신의 브랜치명 prefix에 -subagent(이하 subagent 브랜치) 와 -mainagent(이하 mainagent 브랜치) 냐에 따라 다음을 수행할 것
만약 그러한 prefix가 없다면 기록을 거부할 것

## 공통

- 작업이 끝난 후 rollout-*.jsonl를 읽고 아래과 같이 stats.md 파일에 집계하여 다음과 같이 기록

[메인 에이전트]
- 메인 에이전트의 모델과 추론 수준
- 수행 작업 : (수행 작업에 대한 요약)
 | 구분 | 메인 에이전트 | 서브 에이전트 |
|---|---:|---:|
| 입력 토큰 | 12,162,291 | 113,421 |
| └ 캐시 입력 | 12,118,656 | 62,208 |
| └ 비캐시 입력 | 43,635 | 51,213 |
| 출력 토큰 | 29,098 | 287 |
| └ 추론 출력 | 8,634 | 80 |
| **전체 토큰** | **12,191,389** | **113,708** |

subagent 브랜치는 각 서브에이전트간에 토큰을 얼마나 썼는지도 아래처럼 쓸 것

[서브 에이전트 1 : (서브에이전트 이름)]
- 서브 에이전트 모델 및 추론 수준 : (모델과 추론수준 적으면 됨)
- 수행 작업 : (수행 작업에 대한 요약)
 | 구분 | 사용량 |
|---|---:|---:|
| 입력 토큰 | 12,162,291 |
| └ 캐시 입력 | 12,118,656 |
| └ 비캐시 입력 | 43,635 |
| 출력 토큰 | 29,098 | 
| └ 추론 출력 | 8,634 |
| **전체 토큰** | **12,191,389** |


response_id로 중복을 제거하고 누적값을 합산하지 말것. 
없는 필드는 null로 기록할 것


## 기록 경로

- subagent 브랜치
 /AI-productivity/subagent 아래에 stats_[수행작업].md 에 기록

-mainagent 브랜치
 /AI-productivity/mainagent 아래에 stats_[수행작업].md 에 기록
