# PanelError

통계 패널 안에 넣어 사용하는 범용 오류 안내입니다. 패널 제목·카드 테두리는 부모에서 유지하고, 오류 메시지와 선택적인 재시도 버튼만 표시합니다. 내부에서 API를 호출하거나 자동 재시도하지 않습니다.

## Props

| 이름       | 기본값                                                    | 설명                                          |
| ---------- | --------------------------------------------------------- | --------------------------------------------- |
| title      | 문제가 발생했어요                                         | 오류 안내 제목                                |
| message    | 데이터를 불러오지 못했습니다. 잠시 후 다시 시도해 주세요. | 사용자에게 보여줄 설명                        |
| onRetry    | 없음                                                      | 수동 재시도 함수. 없으면 버튼을 표시하지 않음 |
| retryLabel | 다시 시도                                                 | 재시도 버튼 문구                              |

## 사용 예시

```tsx
import PanelError from "~/components/common/PanelError";

<article>
    <h3>기여자 통계</h3>
    <PanelError onRetry={() => void query.refetch()} />
</article>;
```

`role="alert"`로 오류를 알리고, 아이콘은 장식으로 처리합니다. 기본 버튼은 키보드로 접근할 수 있습니다. 네트워크나 서버 원본 오류는 사용하는 화면에서 사용자용 메시지로 바꿔 전달합니다.
