# PanelLayout

패널 배경, 둥근 모서리, 16px 여백, 테두리 없음, 제목과 부제목 및 바닥글을 공유합니다.
제목은 h3이며, 본문 구성은 children으로 자유롭게 전달합니다.
스타일은 panelLayoutTV의 슬롯 및 appearance 기본 variant에서 관리합니다.

## Props

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| title | ReactNode | 필수 패널 제목 |
| semititle | ReactNode | 선택 부제목 |
| children | ReactNode | 선택 본문 콘텐츠 |
| footer | ReactNode | 선택 바닥글. 분석 기간 또는 안내 |
| appearance | "default" | 기본 스타일 variant. 생략 시 default |

## 사용 예시

```tsx
<PanelLayout title="주 사용 언어" semititle="자주 사용하는 언어 top 5" footer="분석 기간 2025-10-17 ~ 2026-10-17">
    <LanguageChart />
</PanelLayout>
```
