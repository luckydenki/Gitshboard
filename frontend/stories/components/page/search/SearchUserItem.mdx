# SearchUserItem

사용자 또는 조직의 검색 결과와 소유 저장소의 별 합계를 카드로 표시합니다. 내부 링크에는 라우터가 필요합니다.

## Props

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `item` | `SearchUserCardItem` | 사용자 검색 API 항목에 소개, 지역, 별 합계, 프로필 수정 시각을 선택적으로 추가할 수 있습니다. |

## 사용 예시

```tsx
<SearchUserItem item={user} />
```
