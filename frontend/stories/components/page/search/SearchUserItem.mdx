# SearchUserItem

사용자 또는 조직의 검색 결과와 소유 저장소의 별 합계를 카드로 표시합니다. 내부 링크에는 라우터가 필요합니다.

## Props

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `item` | `SearchUserCardItem` | 사용자 검색 API 항목입니다. 소개와 지역은 `null`일 수 있으며, 별 합계는 선택 항목입니다. |

## 사용 예시

```tsx
<SearchUserItem item={user} />
```
