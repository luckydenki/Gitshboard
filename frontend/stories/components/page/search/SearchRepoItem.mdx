# SearchRepoItem

저장소 검색 결과를 언어, 별, 포크와 함께 카드로 표시합니다. 내부 링크에는 라우터가 필요합니다.

## Props

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `item` | `RepositorySearchItem` | 저장소 검색 API의 항목입니다. 설명과 언어는 `null`일 수 있습니다. |

## 사용 예시

```tsx
<SearchRepoItem item={repository} />
```
