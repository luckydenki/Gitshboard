# SearchRepoItem

저장소 검색 결과를 언어, 별, 포크와 함께 카드로 표시합니다. 내부 링크에는 라우터가 필요합니다.

## Props

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `item` | `SearchRepoCard` | 저장소 이름, 소유자, 링크, 설명, 언어, 별과 포크 수, 업데이트 시각을 담은 결과입니다. 설명과 언어는 `null`일 수 있습니다. |

## 사용 예시

```tsx
<SearchRepoItem item={repository} />
```
