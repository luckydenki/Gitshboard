# SearchResultHeader

검색 결과의 전체 건수를 제목으로 표시합니다.

## Props

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `total_count` | `number` | 표시할 전체 검색 결과 건수입니다. |

## 사용 예시

```tsx
<SearchResultHeader total_count={42} />
```
