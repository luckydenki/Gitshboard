# SearchItems

`SearchItems`는 GitHub 사용자 검색 결과에서 각각의 사용자 또는 조직 정보를 표시하는 UI 컴포넌트입니다.

사용자는 검색 결과에 표시된 항목을 선택하여 해당 계정의 실제 GitHub 페이지로 이동할 수 있습니다.

---

## 주요 요구사항

### 1. 검색 결과 표시

`SearchItems`는 GitHub 사용자 검색 결과의 개별 항목을 표시해야 합니다.

검색 결과가 여러 개라면 각각의 검색 결과마다 하나의 `SearchItems`가 렌더링됩니다.

### 2. 계정 정보 구성

각 검색 결과 항목은 다음 정보를 포함해야 합니다.

- GitHub 계정의 프로필 이미지
- GitHub 계정 이름
- 계정 유형을 나타내는 라벨

계정 유형 라벨은 다음 두 종류 중 하나를 표시합니다.

- `User`: 개인 사용자 계정
- `Organization`: 조직 계정

### 3. GitHub 계정 페이지 이동

사용자가 `SearchItems`를 선택하면 해당 계정의 실제 GitHub 페이지로 이동해야 합니다.

예를 들어 `octocat` 계정의 검색 결과라면 다음 주소로 이동합니다.

```text
https://github.com/octocat
````

이 컴포넌트는 페이지 이동을 목적으로 하므로 최상위 상호작용 요소는 가능하면 `button`보다 링크를 나타내는 `<a>` 요소를 사용해야 합니다.

외부 GitHub 페이지를 새 탭에서 열 경우 다음 속성을 함께 사용합니다.

```tsx
<a
  href={htmlUrl}
  target="_blank"
  rel="noopener noreferrer"
>
  {/* 계정 정보 */}
</a>
```

### 4. Hover 상태

사용자가 마우스 포인터를 항목 위에 올리면 현재 선택 가능한 항목임을 알 수 있도록 배경색이 회색 계열로 어두워져야 합니다.

배경색 변화는 갑작스럽지 않도록 짧은 전환 효과를 적용할 수 있습니다.

```css
.search-item {
  transition: background-color 0.2s ease;
}

.search-item:hover {
  background-color: #e5e7eb;
}
```

어두운 테마를 지원한다면 테마에 적합한 hover 색상을 별도로 지정해야 합니다.

## 접근성 요구사항

### 링크 사용

`SearchItems`의 주된 기능은 GitHub 계정 페이지로 이동하는 것이므로 클릭 가능한 최상위 요소는 `<a>`를 사용해야 합니다.

이를 통해 사용자는 다음과 같은 브라우저 기본 기능을 사용할 수 있습니다.

* `Tab` 키를 사용한 포커스 이동
* `Enter` 키를 사용한 링크 실행
* 새 탭에서 링크 열기
* 링크 주소 복사
* 스크린 리더를 통한 링크 인식

### 프로필 이미지 대체 텍스트

프로필 이미지에는 계정 이름을 포함한 대체 텍스트를 제공해야 합니다.

```tsx
<img
  src={avatarUrl}
  alt={`${name} profile`}
/>
```

프로필 이미지가 단순 장식이고 바로 옆에 동일한 계정 이름이 표시된다면 중복 낭독을 방지하기 위해 빈 `alt`를 사용할 수도 있습니다.

```tsx
<img
  src={avatarUrl}
  alt=""
/>
```

### 키보드 포커스

키보드 사용자가 현재 선택한 항목을 확인할 수 있도록 명확한 포커스 스타일을 제공해야 합니다.

```css
.search-item:focus-visible {
  outline: 2px solid currentColor;
  outline-offset: 2px;
}
```

Hover 상태만 구현하고 포커스 상태를 생략해서는 안 됩니다.

### 계정 유형 라벨

`User` 또는 `Organization` 라벨은 색상만으로 구분하지 않고 텍스트를 함께 표시해야 합니다.

```tsx
<span>User</span>
```

```tsx
<span>Organization</span>
```

## 테스트해야 할 동작

`SearchItems` Story 또는 테스트에서는 다음 내용을 검증해야 합니다.

1. 프로필 이미지가 표시되는가
2. 계정 이름이 표시되는가
3. 계정 유형에 따라 올바른 라벨이 표시되는가
4. 항목에 올바른 GitHub 주소가 연결되어 있는가
5. 마우스를 올렸을 때 hover 스타일이 적용되는가
6. `Tab` 키로 항목에 접근할 수 있는가
7. 키보드 포커스가 시각적으로 표시되는가

---

## 사용 예시

```tsx
<SearchItems
  name="octocat"
  avatarUrl="https://github.com/octocat.png"
  htmlUrl="https://github.com/octocat"
  type="User"
/>
```

조직 계정은 다음과 같이 사용할 수 있습니다.

```tsx
<SearchItems
  name="github"
  avatarUrl="https://github.com/github.png"
  htmlUrl="https://github.com/github"
  type="Organization"
/>
```

---

## 사용 시 주의사항

* 단순 페이지 이동에 `onClick`과 `navigate`를 사용하지 않습니다.
* 이동 주소는 GitHub API가 반환한 `html_url` 값을 사용하는 것이 좋습니다.
* 계정 유형은 API에서 전달받은 `type` 값을 기준으로 표시합니다.
* Hover 효과와 함께 키보드 포커스 효과도 반드시 제공합니다.
* 클릭 가능한 영역은 텍스트 일부가 아니라 검색 결과 항목 전체가 되도록 구성합니다.
