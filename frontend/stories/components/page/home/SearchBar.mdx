# SearchBar

GitHub 사용자 또는 저장소를 검색하고 선택적으로 필터를 적용하는 검색 폼입니다. 현재 검색 버튼은 폼 값을 콘솔에 기록합니다.

## 속성

| 속성 | 타입 | 설명 |
| --- | --- | --- |
| `enableFilter` | `boolean` | 검색 필터 표시 여부입니다. 기본값은 `false`입니다. |
| `variant` | `{ wsize?: "sm" \| "md" \| "lg" \| "xl" \| "full" }` | Tailwind Variants 너비 설정입니다. `wsize`의 기본값은 `md`이며 `full`은 최대 너비를 제한하지 않습니다. |

## 사용 예시

```tsx
<SearchBar enableFilter variant={{ wsize: "lg" }} />
```
