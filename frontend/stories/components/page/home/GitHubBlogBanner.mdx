# GitHubBlogBanner

GitHub Blog의 최신 글과 썸네일을 표시하고 다섯 개씩 페이지를 이동합니다.

## 속성

받는 props는 없습니다. TanStack Query를 사용하므로 `QueryClientProvider`가 필요합니다. 로딩 중이거나 데이터가 없으면 아무것도 렌더링하지 않으며, 빈 배열이면 제목과 빈 목록을 표시합니다.

## 사용 예시

```tsx
<QueryClientProvider client={queryClient}>
  <GitHubBlogBanner />
</QueryClientProvider>
```
