# GitHubBlogBanner

Displays the latest GitHub Blog posts and thumbnails, with pagination in groups of five.

## Props

This component accepts no props. It uses TanStack Query and requires a `QueryClientProvider`. It renders nothing while loading or without data; an empty array shows the heading and an empty list.

## Usage

```tsx
<QueryClientProvider client={queryClient}>
  <GitHubBlogBanner />
</QueryClientProvider>
```
