# RepoDashboardCommitStatusSection

기본 브랜치의 완료된 최근 기간 커밋 현황을 개요·차트·전적 카드로 표시합니다. 두 API는 TanStack Query로 조회합니다.

## Props

없습니다. 라우트의 `owner`, `repo` 매개변수와 `QueryClientProvider`가 필요합니다.

## 사용 예시

```tsx
<Route path="/repos/:owner/:repo" element={<RepoDashboardCommitStatusSection />} />
```
