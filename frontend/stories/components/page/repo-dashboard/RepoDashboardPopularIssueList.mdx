# RepoDashboardPopularIssueList
열린 Issue의 관심 순위와 조회 상태를 표시합니다.

## Props
`data`는 API 응답, `loading`은 조회 중 여부, `error`는 오류 여부, `onRetry`는 재시도 동작입니다.

## 사용 예시
```tsx
<RepoDashboardPopularIssueList data={data} loading={false} error={false} onRetry={retry} />
```
