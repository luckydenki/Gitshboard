# RepoCommitStatusWeeklyChart

완료된 기간의 주별 커밋 수를 ECharts 선 그래프로 표시합니다.

## Props

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `points` | `CommitStatusWeek[]` | 각 주의 기간과 커밋 수입니다. |
| `timezone` | `string` | 주 시작 날짜 라벨에 사용할 IANA 시간대입니다. |

## 사용 예시

```tsx
<RepoCommitStatusWeeklyChart points={weekly.points} timezone="Asia/Seoul" />
```
