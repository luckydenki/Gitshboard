# RepoCommitStatusCodeChangeChart

주별 순 코드 변화량을 선 그래프로 표시하며, 호버 정보에 추가·삭제 줄 수를 따로 제공합니다.

## Props

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `points` | `CommitStatusCodeWeek[]` | 주별 순증감·추가·삭제 줄 수입니다. |
| `timezone` | `string` | 주 시작 날짜 라벨에 사용할 IANA 시간대입니다. |

## 사용 예시

```tsx
<RepoCommitStatusCodeChangeChart points={code.points} timezone="Asia/Seoul" />
```
