# RepoCommitStatusRecordsList

최근 완료된 1년의 활동일·주, 평균, 최장 기록 등 커밋 전적을 카드로 표시합니다.

## Props

| 이름      | 타입                          | 설명                           |
| --------- | ----------------------------- | ------------------------------ |
| `records` | `RepoCommitStatusRecordsDto?` | 서버에서 받은 커밋 전적입니다. |
| `loading` | `boolean`                     | 응답 대기 중인지 나타냅니다.   |
| `error`   | `boolean`                     | 조회 오류가 있는지 나타냅니다. |
| `onRetry` | `() => void`                  | 다시 시도 버튼의 동작입니다.   |

## 사용 예시

```tsx
<RepoCommitStatusRecordsList
    records={records}
    loading={false}
    error={false}
    onRetry={refetch}
/>
```
