# RepoDashboardReadmeQueryState

README 목록·본문의 로딩, 오류, 빈 상태를 표시합니다.

## Props

- `kind`: `listLoading`, `listError`, `empty`, `contentLoading`, `contentError` 중 하나입니다.
- `onRetry`: 오류 상태의 다시 시도 버튼 콜백입니다.

## 사용 예시

```tsx
<RepoDashboardReadmeQueryState kind="listError" onRetry={refetch} />
```
