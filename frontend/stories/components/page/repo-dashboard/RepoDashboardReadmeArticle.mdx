# RepoDashboardReadmeArticle

선택한 README 원문을 GFM과 제한된 HTML로 렌더링합니다. 상대 링크는 GitHub 파일 경로에 맞춥니다.

## Props

- `content`: 경로, Markdown, 기본 브랜치, GitHub 파일 URL을 담은 `GetRepoReadmeContentDto`입니다.

## 사용 예시

```tsx
<RepoDashboardReadmeArticle content={readmeContent} />
```
