# RepoDashboardCommunicationSection

기여자·열린 Issue·Discussion·Release API를 표시하고 C 항목의 예시 UI를 유지합니다.

## Props 및 사용 예시

Props 없음. QueryClientProvider와 `/repo/:owner/:repo` 라우트 안에서 `<RepoDashboardCommunicationSection />`을 렌더링합니다.

원래 카드 구성과 배치를 유지하며 각 영역에서 API를 조회합니다. RepoCommunicationQueryState의 props는 pending, error, metric, onRetry와 값 렌더링용 children입니다. 신규 기여자 섹션은 A·B 실데이터와 기존 C 예시를 원래 위치에 함께 표시합니다.
