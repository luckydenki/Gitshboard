# RepoCommitStatusQueryState

커밋 현황 API의 로딩, 오류, 빈 결과, 부분 수집 상태를 표시합니다.

## Props

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `state` | `"loading" \| "error" \| "empty" \| "partial"` | 표시할 조회 상태입니다. |
| `onRetry` | `() => void` | 오류나 부분 수집 상태에서 다시 시도할 때 호출합니다. |

## 사용 예시

```tsx
<RepoCommitStatusQueryState state="error" onRetry={() => refetch()} />
```
