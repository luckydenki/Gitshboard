# 저장소 PR 및 Issue 통계

저장소의 Issue 처리 흐름과 마일스톤, PR 리뷰와 협업 통계를 표시합니다.

`RepoDashboardIssueStatsSection`과 `RepoDashboardPullRequestStatsSection`은 각 API의 `data`를 받습니다. `loading`은 진행 중, `error`는 표시할 오류, `onRetry`는 다시 조회하는 동작입니다. Issue 섹션의 `popular`에는 별도로 조회하는 인기 Issue 카드를 전달합니다. 내부 통계 카드는 `metric`의 수집 상태를 읽고, 값이 있을 때만 각 지표를 렌더링합니다.

```tsx
<RepoDashboardIssueStatsSection data={issues} onRetry={reloadIssues} />
<RepoDashboardPullRequestStatsSection data={pullRequests} onRetry={reloadPullRequests} />
```
