# RepoCommitStatusTimeChart

최근 90일 커밋의 4시간대별 분포를 막대그래프로 표시합니다.

## Props

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `buckets` | `{ startHour: number; count: number }[]` | 0·4·8·12·16·20시 시작 시간대와 커밋 수입니다. |

## 사용 예시

```tsx
<RepoCommitStatusTimeChart buckets={timeOfDay.buckets} />
```
