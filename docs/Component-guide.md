# COMPONENT GUIDE

컴포넌트 구현을 요청할 시 다음과 같은 기본 규칙을 따르세요

1. 컴포넌트 하나당 하나의 파일을 사용하는 게 원칙입니다. 이 경우 `export default function` 문으로 작성하세요
2. 같은 파일 내에 별도의 UI 컴포넌트를 추가해달라고 한다면 `export const` 화살표 함수로 작성해주세요. 반드시 메인 컴포넌트인 `export default function`보다 위에 작성하셔야 합니다.
3. 컴포넌트 분리는 분리 해달라고 부탁하는 게 아니면 하지 말고 그 컴포넌트 파일 내에서 구현해주세요
