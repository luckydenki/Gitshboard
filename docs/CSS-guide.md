# CSS GUIDE

UI를 만들 경우, 다음 CSS 가이드를 지키세요


## 색상
1. 주 색은 `primary`입니다. `ex: bg-primary` 강조하고 싶은 경우 이것을 활용하세요.
2. 텍스트 회색은 `gray-500` 입니다.
3. 경계선 회색은 `gray-300` 입니다. 다만 대비율이 좋지 않다면 이보다 낮거나 높은 `gray-200`이나 `gray-400`까지도 허용합니다.
4. 모든 패널 색은 `panel`입니다 `ex: bg-panel`

## 경계선
1. 모든 경계선 둥글기는 `rounded-lg`입니다.
2. 호버링을 위한 효과를 제외한 모든 border 크기는 1입니다 (`border-1`)

## 효과
1. 모든 버튼을 만들 때에는 반드시 `cursor-pointer`를 추가하세요
2. 호버링 효과에 사이즈 변화 애니메이션을 넣지마세요. 호버링 효과는 배경색 변경 또는 경계선 색 변경, 경계선 굵기 변경만으로도 충분합니다. 그러한 효과를 요구할 때만 넣으세요.
3. 그림자 넣지 마세요.
4. 그라데이션과 꾸밈 도형을 넣지 마세요.

## 레이아웃
1. 모든 요소의 패딩은 최소 `p-2`에서 최대 `p-8`까지의 범위로 제한하세요. (px와 py 모두 동일 적용)
2. 리스트 간 간격은 마진을 쓰지 말고 `gap`을 사용하세요.
3. 리스트를 열거시킬 때는 grid를 쓰지말고 `flex` (+`flex-col`)을 사용하세요
4. 구분선은 `divide`계열로 만드세요
5. `main` 태그는 각 페이지당 최대 하나만 존재하게 되어있으며, main은 `main-x-side`만큼의 `px`패딩을 가져야 합니다. (ex:`px-main-x-side`)

## 그 외 기타
1. `border-1` 같은 건 `border`로 대체 가능하고 `w-[100%]`는 `w-full`로 대체 가능합니다. 이렇듯 최대한 축약시킬 수 있는 표현을 사용하세요.
