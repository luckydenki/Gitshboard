# CSS 및 STYLE GUIDE

UI를 만들 경우, 다음 CSS 및 STYLE 가이드를 지키세요

## Tailwind CSS 클래스 작성 규칙

- Tailwind CSS 클래스 작성 시 동일한 스타일을 표현하는 여러 방법이 있다면 공식 권장 표준 클래스(Canonical Class)를 우선 사용하세요.
- Tailwind CSS IntelliSense의 suggestCanonicalClasses 경고가 발생하는 표현은 가능한 한 피하세요.
ex: `border-1` 대신 `border` 를 사용할 것.

## 색상
1. 주 색은 `primary`입니다. `ex: bg-primary` 강조하고 싶은 경우 이것을 활용하세요.
2. 텍스트 회색은 `gray-500` 입니다.
3. 경계선 회색은 `gray-300` 입니다. 다만 대비율이 좋지 않다면 이보다 낮거나 높은 `gray-200`이나 `gray-400`까지도 허용합니다.
4. 모든 패널 색은 `panel`입니다 `ex: bg-panel`
5. 주 색을 되도록 너무 많은 비율로 사용하지 마세요. 디자인에서 말하는 6:3:1 법칙에 따라, 주색과 보조색은 검정, 하양이라고 생각하고 1의 비율로 primary를 사용해주세요.

## 경계선
1. 경계선 넣어야 하는 상황에서 둥글기는 `rounded-lg`로 통일하세요.
2. 호버링을 위한 효과를 제외한 모든 border 크기는 1입니다 (`border-1`)
3. 패널 경계선을 넣는 것은 경계선이 필요해야 할 정도로 구분감이 없는 상황에서만 넣으세요
예시 : 배경색과 패널색의 차이로 인한 구분감이 충분히 가능 한 경우 경계선을 넣을 필요가 없음

## 효과
1. 모든 버튼을 만들 때에는 반드시 `cursor-pointer`를 추가하세요
2. 호버링 효과에 사이즈 변화 애니메이션을 넣지마세요. 호버링 효과는 배경색 변경 또는 경계선 색 변경, 경계선 굵기 변경만으로도 충분합니다.
3. 그림자 넣지 마세요.
4. 그라데이션과 꾸밈 도형을 넣지 마세요.
5. 모든 텍스트 링크형 UI는 호버링 시 `cursor-pointer`와 `underline`을 두세요. 
6. 햄버거 ui를 눌러 메뉴를 보여줄 경우 우상에서 좌하로 scale이 90%->100% 까지 커지는 애니메이션을 넣으세요 

## 레이아웃
1. 모든 요소의 패딩은 최소 `p-2`에서 최대 `p-8`까지의 범위로 제한하세요. (px와 py 모두 동일 적용)
2. 리스트 간 간격은 마진을 쓰지 말고 `gap`을 사용하세요.
3. 리스트를 열거시킬 때는 grid를 쓰지말고 `flex` (+`flex-col`)을 사용하세요
4. 구분선은 `divide`계열로 만드세요
5. `main` 태그는 각 페이지당 최대 하나만 존재하게 되어있으며, main은 `main-x-side`만큼의 `px`패딩을 가져야 합니다. (ex:`px-main-x-side`)

## 변종
1. 만약 어떤 컴포넌트가 props에 따라 다른 스타일을 보이게 만들어야 하는 요구사항이라면 tailwind variant를 사용해 스타일을 만드세요. 
2. 모든 tailwind variant는 뒤에 `TV`가 붙어있게 해주세요
3. tailwind variant는 `VariantProps`를 통해 props 타입을 추출하여 컴포넌트 props에서 받도록 만드세요


## 예외 UI

2. 스켈레톤과 원본 UI의 상하 길이가 최대한 비슷하게 맞추세요
3. 데이터가 없는 상태 UI도 데이터가 최소 한개는 존재할 때의 높이로 만드세요.
