- **정상 응답 확인.** Chrome 1905px 너비에서 `/user/fluetanol/repos`를 열어 공개 저장소 21개, 받은 스타 8개, 포크 0개와 카드 목록이 표시되는 것을 확인했습니다.

- **카드 이동 재확인.** 이후 카드 전체를 서비스 내 저장소 전적 링크로 연결했습니다. Chrome에서 `/user/fluetanol/repos`의 `React-Github` 카드를 눌러 `/repo/fluetanol%2FReact-Github`로 이동하는 것을 확인했습니다. 도착 페이지에는 `facebook/react` 예시 데이터가 표시되고 README 탭의 링크에는 `%252F`가 포함되어 있습니다. 저장소 전적의 데이터 연동 및 하위 탭 이동을 확인할 때 함께 점검할 항목입니다.
