# 개인 통계 API 연동 UX 점검

Chrome에서 `http://localhost:5173/user/fluetanol`을 열었습니다. 프로필 정보와 최근 활동 10건이 표시됐고, 분류에서 커밋을 선택하면 빈 목록 안내로 바뀌었습니다.

- **분류 범위 안내 수정.** 최근 활동 10건이 모두 이슈일 때 커밋을 선택하면 빈 목록이 표시됩니다. 분류가 최근 최대 10건에 적용된다는 안내를 추가했습니다. 수정된 문구는 소스에서 확인했으며 브라우저에서 재확인하지 않았습니다.
- **캘린더 시각 확인 보류.** 같은 페이지에서 캘린더 영역을 확인했으나 브라우저 캡처가 시간 초과되어 실제 차트의 표시 상태를 확인하지 못했습니다. 다음 점검에서 날짜별 칸과 마우스 오버 정보를 확인해야 합니다.
- **좁은 화면과 로딩·오류 상태 확인 보류.** 기존 브라우저의 정상 응답 상태에서 점검했습니다. 좁은 화면에서의 배치와 API 지연·실패 시 안내는 확인하지 못했습니다.
