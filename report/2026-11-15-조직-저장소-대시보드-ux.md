# 조직 저장소 대시보드 UX 점검

- 점검 화면: `/org/ZipsAR/repos`
- 실제 브라우저 확인: 1905px에서 정상 응답 및 로딩, 390px에서 정상 응답. 저장소 2개와 통계, 카드 링크, 로딩 스켈레톤을 확인함.
- 수정 완료: 390px에서 통계 라벨이 좁게 줄바꿈되던 문제. 공통 통계를 모바일 1열, `sm` 이상 3열로 변경함. 변경 후 브라우저 재확인은 진행하지 않음.
- 기존 미해결 문제: 390px에서 페이지가 약 10px 가로로 넘침. 기존 조직 프로필의 `min-w-sm`이 원인이며, 이번 저장소 컴포넌트 범위에서는 수정하지 않음. 프로필 레이아웃 작업 시 같은 너비에서 재확인 필요.
- 확인하지 못한 상태: 저장소 API의 빈 응답과 오류는 코드의 안내 문구 분기만 확인함. 각 응답을 브라우저에서 재현해 표시를 확인할 필요가 있음.
- 키보드 포커스: 카드 링크의 `focus-visible` 스타일은 코드에서 확인했으며 실제 키보드 조작은 확인하지 못함.
- 조직 프로필 API는 점검 중 실패했으나 저장소 API는 정상 응답함. 프로필 실패 원인은 이번 점검에서 확인하지 않음.
