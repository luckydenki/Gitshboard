# 연속 활동 일수 UX 점검

- **연속 활동 표시 확인 완료.** 로컬 API에서 `fluetanol`은 0일, `torvalds`는 25일을 반환했습니다. Chrome에서 두 계정의 최근 활동 탭을 열어 각각 ‘최근 연속 활동 없음’과 ‘25일 연속 활동 중’이 표시되는 것을 확인했습니다.
- **최근 활동 목록 로딩 개선.** 초기 점검에서는 1054px 화면에서 로딩 문구 한 줄 아래로 목록 영역이 비어 있었습니다. 목록과 같은 패널 안에 최대 10개 행의 스켈레톤을 표시하도록 수정했습니다.
- **로딩 개선 재확인.** Chrome에서 네트워크를 느리게 설정하고 최근 활동 페이지를 새로고침했습니다. 1905px 너비에서 로딩 중 목록 영역이 여러 행의 스켈레톤으로 채워지는 것을 확인했습니다. 실제 행이 스켈레톤보다 높을 수 있어 약간의 세로 이동은 남을 수 있습니다. 좁은 화면에서의 로딩은 재확인하지 않았습니다.
