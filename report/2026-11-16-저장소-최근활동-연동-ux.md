# 저장소 최근 활동 API 연동 UX 점검

- 데스크톱 1905×901에서 `/repo/torvalds/linux`에 처음 진입하면 요약과 목록이 각각 로딩 상태를 표시한다. 데이터 도착 후 요약 카드와 최근 전적 6건이 표시됐다. 로딩 영역이 작아 실제 콘텐츠가 들어올 때 화면 높이가 크게 늘어난다. 위치 이동이 문제로 제기되면 느린 연결에서 초기 영역 높이를 비교할 수 있다.
- 모바일 390×844에서는 요약과 목록이 세로로 배치되고 목록을 읽을 수 있다. 가로 스크롤은 상단 저장소 헤더가 보이는 상태에서도 발생했다. 원인 범위를 확인하려면 같은 너비에서 다른 저장소 탭과 비교할 수 있다.
- 빈 결과와 API 실패는 브라우저에서 재현하지 않았다. 빈 목록은 기존 목록 컴포넌트가 안내하며, 각 요청 실패는 해당 영역에서 재시도할 수 있도록 구현했다.
- 모바일에서 더 보기를 눌러 로딩 중 비활성화 상태를 확인했다. 응답 후 기존 6건 뒤에 다음 6건이 추가됐고 버튼이 다시 활성화됐다.
